# Svenska språkigenkänning (proef)

Proef met lokale modellen (Docker) voor Zweedse spraakherkenning en uitspraakcontrole, met als doel op termijn
spreekopdrachten in de oefensite. Zie `PLAN.md` voor kandidaten, opzet en criteria, en `testzinnen.tsv` voor
wat er ingesproken moet worden (bestanden naar `opnames/<id>.wav`).
